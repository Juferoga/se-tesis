# Publicación del código

Pasos para archivar la versión del artículo con un DOI permanente:

- [x] Crear una versión (tag), por ejemplo `v1.0-tecnologicas`, desde `main`.
- [x] Activar el repositorio `Juferoga/se-tesis` en la sección *GitHub* de https://zenodo.org.
- [x] Publicar la versión (release) en GitHub; Zenodo la archiva y asigna el DOI automáticamente.
- [x] Agregar el distintivo del DOI al README y un archivo `CITATION.cff`.
- [x] Citar el DOI en el apartado 2.8 del artículo, además del enlace a GitHub.
